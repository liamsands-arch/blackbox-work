1. The block in your instructions

The only thing that ever wrote this block is VG Brain's first-run setup, in vg-brain/src/vg-brain-setup.ts. Your stale text is word for word its first version from May 27. It was rewritten May 31, and setup has been hidden from Claude since then, so it could not have put the old text back in November. An old copy most likely came back from outside our code, for example through Claude's import of settings.

The fix: setup no longer writes any block into anyone's instructions. The connector already tells every chat when to search and that nothing saves without a yes.

Before: setup wrote this (May 27 version, the one you found)

VG Brain is the user's persistent memory across sessions. Things from

READ FROM IT FIRST when the user asks about anything that might predate

WRITE TO IT proactively when something in this chat is worth remembering
